# TaskFlow 課業與專題進度管理系統

## 開發動機
學生的作業、考試及專題任務常散落在多種平台，因此本專案整合任務與期限，提供簡單的個人管理工具。

## 功能
- 新增、編輯、刪除、標記完成任務
- 區分作業／考試／專題／其他
- 高中低優先度、截止日期、備註
- 搜尋與狀態篩選（含逾期及三日內到期）
- 顯示任務總數、已完成、待完成、逾期、完成率
- SQLite 資料永久儲存在本機 `tasks.db`（第一次運作時自動建立）

## 執行方法（Windows / Mac / Linux）
1. 安裝 Python 3.9 以上版本。
2. 解壓縮 ZIP，在資料夾開啟終端機。
3. 執行：`python app.py`（Windows 也可以用 `py app.py`）。
4. 瀏覽器開啟 http://127.0.0.1:8000。
5. 按 Ctrl+C 關閉。

**無需 pip install，也不需要網路或 API 金鑰。** 資料保存在本機，不支援多人同時遠端使用。

## 測試
`python -m unittest test_app.py -v`

## 程式結構
- `app.py`：HTTP 伺服器、REST API、SQLite CRUD、資料驗證及統計
- `index.html`：前端版面、表單、搜尋、篩選、使用者互動
- `test_app.py`：基本測試

## 專案價值
**使用價值**：減少遺忘截止日期，提高學習及專題管理效率。目標使用者為學生或小型團隊。

**商業模式假設**：基本個人版免費，未來可開發帳號同步、團隊協作、Email 通知、共享看板等付費功能，或承接社團／工作室客製化任務系統。這些功能目前尚未實作，尚未驗證付費需求。
