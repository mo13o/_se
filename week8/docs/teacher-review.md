# TaskFlow Level 3 老師檢閱指南

## 專案目標

TaskFlow 是以 React、TypeScript、FastAPI 與 SQLite 製作的智慧課業及多人專題進度管理平台。Level 1 原型保留於 `legacy/`，目前展示版涵蓋個人課業、課程課表、月曆提醒、團隊專案、任務指派、進度看板及報表匯出。

## 建議檢閱動線（約 5–8 分鐘）

1. 註冊或以 Demo 帳號登入，確認不同帳號資料隔離。
2. 在「任務」新增作業或考試，觀察統計卡與搜尋篩選。
3. 在「課程」建立課程資料。
4. 到「行事曆」查看月曆，切換月份並點選任務或每週課程事件。
5. 在「團隊」建立團隊，再到「專案看板／甘特」建立專案。
6. 建立專案任務、指定負責人，依序切換「待處理／進行中／待審核／已完成」。
7. 專案有任務後下載 CSV 或 PDF 週報。
8. 到「通知」查看三天內到期與逾期提醒。

## 功能與技術對照

| 範圍 | 展示功能 | 技術重點 |
|---|---|---|
| 帳號 | 註冊、登入、Cookie session、資料隔離 | Argon2id、CSRF、登入節流 |
| 個人課業 | 任務 CRUD、分類、優先級、統計 | React 狀態管理、FastAPI、SQLite |
| 課程行事曆 | 課程資料、每週課表 API、月曆事件 | 日期區間限制、重疊檢查、月曆渲染 |
| 團隊專案 | 團隊、專案、成員角色、任務指派 | Owner/Admin/Member 權限與 IDOR 防護 |
| 專案進度 | 四階段狀態、負責人、截止日期 | 看板狀態更新、單一負責人驗證 |
| 報表 | UTF-8 CSV、中文 PDF 週報 | 權限檢查、ReportLab |

## 本機啟動

建議使用 Docker：

```powershell
docker compose up --build
```

前端為 `http://127.0.0.1:5173`，API 文件為 `http://127.0.0.1:8000/docs`。

## 測試

```powershell
cd backend
pytest -q
cd ../frontend
npm test
npm run build
```

## 展示資料與隱私

請只使用虛構姓名、課表與專案內容。Demo seed 帳密只供本機展示，不應部署於公開環境。
